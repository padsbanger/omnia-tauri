# Omnia Tauri 0.11.5

- Fix file dragging into hosted websites, including Facebook Messenger, by allowing browser-native file drops in route views and popups.
- Add deterministic native WebView2 file-input and drop-upload checks, including popup uploads and privileged-command rejection.

The user confirmed that Messenger file dragging works in the rebuilt Windows app. Native fixture tests also verified uploaded file names, sizes and contents. Automated drops use CDP and do not independently exercise Explorer/OLE drag interception. Linux/macOS uploads and other provider workflows remain unverified.

Frontend checks (118 tests, coverage and CRAP), Rust checks (26 tests, fmt and clippy), Windows fixture smoke and Windows packaging passed for the fix. Version 0.11.5 passed frontend/Rust checks; local packaging could not replace the running application, which was left open. Installers are attached automatically after GitHub Actions verification and platform builds succeed. Linux native smoke remains opt-in because of the previously documented instability.
