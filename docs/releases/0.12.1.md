# Omnia Tauri 0.12.1

Fixed external links in Telegram Web A. Links to other websites now open in your default browser and leave the Telegram conversation open in Omnia.

The fix passed a Windows WebView2 regression test, and a user confirmed that a real Telegram link opened in their browser. [Windows test evidence](https://github.com/padsbanger/omnia-tauri/blob/0.12.1/docs/evidence/windows-telegram-external-links.json)

GitHub Actions attaches the Windows, macOS, and Linux installers after the platform builds pass.
