# Omnia Tauri 0.12.2

Omnia now uses `auth.zaton.net` for account sign-in. The previous Authentik host returned HTTP 525 and prevented Omnia from opening the sign-in window.

If you set `AUTHENTIK_DISCOVERY_URL` or `discovery_url` in `config.json`, update it to the new discovery URL. The host change selects a new local profile namespace, so sign in to Omnia and your hosted sites again. [Configuration instructions](https://github.com/padsbanger/omnia-tauri/blob/0.12.2/README.md#configuration)

GitHub Actions attaches the Windows, macOS, and Linux installers after the platform builds pass.
