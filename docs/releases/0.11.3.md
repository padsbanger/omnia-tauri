# Omnia Tauri 0.11.3

Patch release prepared on 2026-10-24, following 0.11.2.

## Fixes

- Restore file downloads from hosted services such as Gmail, Telegram and Messenger by installing explicit native download handlers on route webviews and their popup windows.
- Permit the narrow automatic-download permission while retaining the existing denial for unrelated portable permission kinds and the Windows requester/top-level origin checks.
- Save to the operating system Downloads directory with sanitized filenames and collision suffixes instead of silently overwriting existing files.
- Show download start, completion and failure states in the trusted Omnia shell without exposing filesystem paths or download URLs to hosted pages.

## Verification

The real Windows WebView2 fixture downloaded and content-verified an HTTP attachment twice (`fixture-download.txt` and `fixture-download (1).txt`) and a page-created blob (`fixture-blob.txt`). The native trace recorded three requests and three successful completions. The same run passed the existing lifecycle, isolation, popup, navigation, OIDC/API, unread and Telegram checks before reaching the previously documented live-drawer desktop-pixel prerequisite, where screen sampling returned black instead of the expected fixture blue. The download scenario is verified; that run is not represented as a complete suite pass.

Passed locally on Windows: lint, typecheck, frontend build, 118 frontend tests with 92.97% statement and 88.49% branch coverage, CRAP threshold 8, 26 Rust tests, fmt, clippy and release packaging. Windows MSI/NSIS checksums are recorded in [0.11.3-SHA256SUMS.txt](0.11.3-SHA256SUMS.txt).

## Upgrade notes and limitations

The application identity, backend configuration, credential namespace and website profile paths are unchanged. Existing hosted-service sessions are retained. Downloads go to the user's normal Downloads folder.

No real Gmail, Telegram or Messenger account was used during automated verification. Linux and macOS share the handler implementation, and the Linux native regression has been added, but neither platform was executed for this change on the Windows host. Existing provider, DRM, notification and Linux graphics-shutdown limitations remain documented in [platform support](../platform-support.md).
